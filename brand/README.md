# Brand masters

Original logo artwork, kept out of `public/` so it is not served with the site.
Everything the site actually loads is derived from these files.

| Master | Derivatives |
| --- | --- |
| `submark.png` — circular badge | `public/images/logo-badge.webp` (header), `public/og-image.png` |
| `primary.png` — stacked lockup | `public/images/logo-stacked.webp` (footer) |
| `Icon.png` — ST monogram | `public/favicon.ico`, `favicon.svg`, `favicon-32.png`, `icon-512.png`, `apple-touch-icon.png` |

The icons composite the cream monogram onto an ink `#2a2818` plate — cream on
transparent disappears in a light browser tab.

Derivatives were resampled with Lanczos rather than vector-traced: the artwork
depends on hairline serifs and ring text set at roughly 1/26th of the badge
diameter, which auto-tracing rounds off. If the original vector files turn up,
use those instead.
